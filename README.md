이 프로젝트는 서울시 청년들의 비만 문제를 공공 데이터를 활용하여 심층적으로 분석하고, 이를 바탕으로 데이터 기반의 맞춤형 비만 정책 대안을 제안하는 것을 목표로 한다. 질병관리청 지역사회건강조사, 서울시 체육시설 및 상권 데이터 등 다양한 공공 데이터를 수집하고 전처리하여, 회귀분석, 클러스터링, 연관성 분석 등 6대 분석 기법을 교차 적용함으로써 청년 비만의 결정요인을 규명하고 25개 자치구별 환경적 특성을 고려한 차등화된 정책 처방을 도출한다. 본 프로젝트의 최종 산출물로는 데이터사이언스 기법이 적용된 Jupyter Notebook 형태의 소스코드와 분석 보고서가 제공된다.
