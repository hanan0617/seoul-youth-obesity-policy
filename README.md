# 서울 청년 비만 진단 및 정책 타겟팅
### Seoul Youth Obesity Diagnosis & Data-Driven Policy Proposal

> 🏆 **DCS 대학생 논문경진대회 금상 수상작**  
> 데이터사이언스개론 PBL #2 | 하이파이브 팀 | 2026-1

---

## 📌 프로젝트 개요

서울 청년 비만(27.3%)을 **개인 의지 문제가 아닌 거주 지역의 구조적 환경 문제**로 재정의하고,  
공공데이터 기반의 6대 분석기법을 교차 적용하여 25개 자치구별 맞춤 정책을 제안한다.

| 가설 | 내용 | 검증 결과 |
|---|---|---|
| H1 | 배달친화 외식환경 ↑ → 청년 비만율 ↑ | ✅ 채택 (r=+0.64, β=103.2) |
| H2 | 체육시설 ↑ → 청년 비만율 ↓ | ⚠️ 부분 지지 (r=−0.31) |

---

## 🔬 적용 분석 기법 (6대)

| 기법 | 목적 |
|---|---|
| K-Means / 계층적 군집 | 25개 자치구 정책 그룹화 |
| 선형 회귀 (OLS) | 개인 BMI 결정요인 규명 |
| 로지스틱 회귀 | 비만 위험요인 Odds Ratio 정량화 |
| 의사결정트리 / 랜덤포레스트 | 비만 여부 분류 및 변수 중요도 |
| 연관 분석 (Apriori) | 위험요인 동시발생 패턴 발굴 |
